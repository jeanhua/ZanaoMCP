# 赞哦舆情分析工作流（MCP）

## Step 1：数据采集

根据话题或关键词采集数据：

```
# 1. 查看分类
campus_market_get_categories()

# 2. 实时搜索（至少 2~3 个关键词变体）
campus_market_search_posts(keyword="关键词A")
campus_market_search_posts(keyword="关键词B")

# 3. 历史搜索
campus_market_search_history_posts(keyword="关键词A", range="1m")

# 4. 热门帖子
campus_market_hot_posts()

# 5. 重要帖子取评论
campus_market_get_comments(thread_id="<帖子ID>")
```

**采集目标：**
- 相关帖子 ≥ 10 条（不足时放宽关键词或扩大时间范围）
- 重点帖子各取评论 ≥ 20 条

## Step 2：数据整理

按维度整理（内部处理）：标题/内容摘要、发布时间、点赞数、评论数、评论内容。

> 帖子接口同时返回图片链接（文本里的 `[图片: https://...]`，或字段 `img_paths`），整理时保留，便于解读图文类热帖。

## Step 3：情感分析

- **正向**：支持、认可、期待、满意
- **负向**：不满、质疑、抱怨、愤怒
- **中性**：陈述事实、询问信息、无明显情绪

统计分布比例，判断总体基调。

## Step 4：观点聚类

相似观点归为若干「观点簇」，每簇含：核心主张、代表性原文（1~2 条）、帖子/评论数量、情感倾向。

## Step 5：热度评估

```
热度指数 = (相关帖子数 × 2) + (总点赞数 × 0.5) + (总评论数 × 1.5)
```

热度等级：
- 🔥🔥🔥 高热（> 200）
- 🔥🔥 中热（100~200）
- 🔥 低热（< 100）

## Step 6：输出报告

按结构输出（中文），**必须使用 shareimg 工具发送图片**，不能发送文本消息。

## 注意事项

1. 引用原文不暴露用户 ID 或可识别身份信息
2. 分析保持中立，不对话题作价值判断
3. 数据样本不足 5 条时，告知用户结论仅供参考
